# Practical Techniques for Navigating Large C++ Codebases as Text in Linux

## Basic Text Search & Analysis

### Finding Classes and Definitions

```bash
# Find all class definitions
grep -rn "class[[:space:]]\+[A-Za-z0-9_]\+" --include="*.h" --include="*.cpp" .

# Find template classes
grep -rn "template[[:space:]]*<.*>[[:space:]]*class" --include="*.h" .

# Locate virtual function implementations
ripgrep "^[[:space:]]*virtual.*\(" --type cpp
```

### Function Call Analysis

```bash
# Extract function calls to a specific function
grep -ro "\bSomeFunction\s*(" --include="*.cpp" . | wc -l

# Find all overloaded operators
ripgrep -n "operator[[:space:]]*(\+|-|\*|/|=|==|\[\]|\(\))" --type cpp
```

## Advanced Pattern Matching

### Extracting Class Hierarchies

```bash
# Find inheritance relationships
grep -rn "class[[:space:]]\+[A-Za-z0-9_]\+[[:space:]]*:[[:space:]]*\(public\|protected\|private\)" . 

# Extract complete class hierarchies with awk
grep -rn "class" --include="*.h" . | awk '/class[[:space:]]+[A-Za-z0-9_]+[[:space:]]*:/ {print $0}'
```

### Finding Complex Patterns

```bash
# Find smart pointer usage
ripgrep "std::(shared|unique|weak)_ptr<\w+>" --type cpp

# Find lambda expressions
ripgrep "\[\s*(?:[&=,\w]+\s*)?\]\s*(?:\([^)]*\))?\s*(?:mutable)?\s*(?:->)?\s*\{" --type cpp

# Extract templated function instantiations
grep -rn "template[[:space:]]*<.*>[[:space:]]*\w\+[[:space:]]*(" --include="*.cpp" .
```

## Practical Workflows

### Building Code Structure Maps

```bash
# Create a quick class dependency graph
grep -rn "class" --include="*.h" . | cut -d':' -f1 | xargs grep -l "#include" | sort | uniq -c | sort -nr

# Find unused headers
for file in $(find . -name "*.h"); do 
  if ! grep -q $(basename $file) --include="*.cpp" .; then 
    echo "Potentially unused: $file"; 
  fi
done
```

### Context-Based Navigation

```bash
# Find where a function is called with context (5 lines before and after)
ripgrep -A 5 -B 5 "someFunction\(" --type cpp

# Find all switch statements and their cases
awk '/switch\s*\(.*\)/{flag=1;print;next} /case\s+.*:/{if(flag)print} /default:/{if(flag)print} /}/{if(flag){flag=0;print}}' $(find . -name "*.cpp")
```

## Batch Editing

```bash
# Replace a deprecated API across the codebase
find . -name "*.cpp" -o -name "*.h" | xargs sed -i 's/OldFunction(/NewFunction(/g'

# Add missing include guards to header files
for file in $(find . -name "*.h" | xargs grep -L "#ifndef"); do
  header_guard="_$(basename $file | tr '[:lower:].' '[:upper:]_')_"
  sed -i "1i#ifndef $header_guard\n#define $header_guard\n\n" $file
  echo -e "\n#endif // $header_guard" >> $file
done
```

## Advanced Text Analysis

```bash
# Create a basic code complexity heatmap by counting nested braces
find . -name "*.cpp" | xargs awk '{brace=0; for(i=1;i<=length;i++) { if(substr($0,i,1)=="{") brace++; } if(brace>5) print FILENAME":"NR" - Highly nested block"}' 

# Find the most complex functions (by line count)
ripgrep -n "^[^{;]+\{" --include="*.cpp" | while read line; do 
  file=$(echo $line | cut -d: -f1); 
  start=$(echo $line | cut -d: -f2); 
  func=$(echo $line | cut -d: -f3-); 
  end=$(tail -n +$start $file | grep -n "^}" | head -1 | cut -d: -f1); 
  echo "$file:$func - $((end)) lines"; 
done | sort -t- -k2 -nr | head -20
```

These techniques allow you to quickly gain insights into large C++ codebases without relying on language-specific tooling. They're particularly useful when working with unfamiliar code or when your normal IDE/tooling isn't available.
